# PICK Social Club Go-Live Checklist

## Stage Before Production

- deploy a private staging URL
- test all three roles on stage
- confirm campaign create/edit flow
- confirm CSV code upload
- confirm influencer join and proof submission flow
- confirm manager and influencer password reset flow
- confirm banners and uploads display correctly

## Data Checks

- remove demo accounts you do not need
- confirm cities, categories, platforms, and tags
- confirm branches and maps links
- confirm campaign banners
- confirm code CSV format with the operations team

## Operations Checks

- agree who owns:
  - influencer approval
  - master data updates
  - campaign publishing
  - code upload
  - reminder follow-up
- agree how offline reservations should be handled

## Before Production

- move from file store to database
- move uploads to durable storage
- harden password handling
- separate staging and production environments
- define backup and recovery plan
- define support owner for stage users
